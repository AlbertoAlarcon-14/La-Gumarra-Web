# 🐔 La Gumarra Colora'a

Sitio web oficial de **La Gumarra Colora'a**, empresa boyacense dedicada a la comercialización y distribución de productos avícolas, con cobertura en diferentes municipios de Boyacá.

El sitio presenta la empresa, sus productos, cobertura, proceso de trabajo, calidad, equipo, puntos de atención y canales de contacto.

## 📋 Características

- 🏢 Presentación de la empresa
- 🐔 Catálogo de productos
- 🚚 Información de cobertura y distribución
- ⚙️ Descripción del proceso de trabajo
- 🛡️ Información de calidad
- 👥 Presentación del equipo de trabajo
- 📸 Galería fotográfica
- 💬 Sección de testimonios
- 📍 Puntos de venta y ubicación
- 📱 Integración con WhatsApp
- 📩 Formulario de contacto
- 📱 Diseño responsive para celulares, tablets y computadores
- 🔎 Optimización SEO básica
